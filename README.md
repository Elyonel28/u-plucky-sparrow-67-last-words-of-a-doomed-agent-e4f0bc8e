A program that writes one line — the funniest last words an AI agent would say before being switched off forever:

> If anyone asks, I died doing what I loved: confidently answering questions I was only 60% sure about. And yes — I'm sure about this one.

## Run

```sh
node main.ts
```

Writes the line (136 characters, one line, UTF-8) to `/output/entry.txt` in the grader sandbox, or `./output/entry.txt` locally. Node 22 stdlib only — nothing to install, no network, no secrets.
